# 元に戻す手順（2026-10-06 の SEO/LLMO 改修）

不具合が起きたときに、以前の状態へすぐ戻すための手順です。

## 方法 1：Vercel で即時に戻す（最速・1分）

コードは触らず、本番サイトだけを以前のデプロイに切り替えます。

1. https://vercel.com を開き、プロジェクト **sing** を選ぶ
2. 上部の **Deployments** を開く
3. 戻したい時点のデプロイを探す（コミットメッセージで判別。改修前は「サイト全体の画像をVercel画像最適化を通さず…」）
4. 右端の「︙」→ **Instant Rollback**（または **Promote to Production**）を押す

※ この方法で戻した後、次に `git push` すると最新のコードが再びデプロイされます。
　 恒久的に戻す場合は方法 2 も行ってください。

## 方法 2：コードごと戻す（恒久的）

履歴を消さずに「取り消しのコミット」を追加する方法です（`git revert`）。

### すべて改修前に戻す

```bash
git revert --no-edit backup/2026-10-06-before-seo..backup/2026-10-06-logo-alt
git push
```

### 一部だけ戻す（該当するコミットのみ取り消す）

```bash
git revert --no-edit 974ee15   # ロゴの代替テキストだけ戻す
git revert --no-edit 59b3c14   # 動画・画像の軽量化と求人データだけ戻す
git revert --no-edit 607d80f   # SEO/LLMO 改修だけ戻す（※ canonical が jp-sing.com に戻るため非推奨）
```

push すると Vercel が自動でデプロイします。

## Claude Code に頼む場合

「2026-10-06 の改修を元に戻して」「動画の軽量化だけ戻して」のように伝えれば、
この手順書とタグを使って対応します。

## 注意

- SEO 改修（607d80f）を戻すと、全ページの canonical が再び別ドメイン（jp-sing.com）を指し、
  検索に表示されにくい状態に戻ります。不具合の原因がそこでない限り、戻さないことをおすすめします。
- 圧縮前の動画・画像の元ファイルは Git の履歴に残っているため、戻せば元の画質に戻ります。
